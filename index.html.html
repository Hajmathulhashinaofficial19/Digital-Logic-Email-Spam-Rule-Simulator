About this model

A = unverified sender · B = spam keywords · C = suspicious link · D = suspicious attachment.

Design rule: a dangerous attachment (D) is spam on its own; a suspicious link (C) only matters combined with an unverified sender or spam wording (A or B); an unverified sender using spam wording (A·B) is spam even with no link or attachment.

Minimizing the raw expression D + C(A+B) + AB via Quine–McCluskey yields the equivalent, already-minimal form F = D + AB + AC + BC — a dangerous-attachment override OR-ed with a majority (2-of-3) vote over {A, B, C}.
